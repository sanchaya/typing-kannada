# Learn Kannada Typing on Your Own Keyboard (Tutorial)

By the end, you will be typing Kannada on your regular keyboard, with a tutor that shows you the exact keys to press and tracks your speed. You will understand the four layouts the app teaches and pick the one that fits you.

## What you'll need

- A computer with a keyboard (laptop or desktop).
- A modern browser (Chrome, Firefox, Safari, Edge).
- No installation. The app is a plain web page. If you have the repo locally, serve it once with `python3 -m http.server 8080` and open `http://localhost:8080`. Otherwise, open the deployed site at `https://typekannada.sanchaya.net/`.

## Step 1: Choose a layout

The layout picker sits in the header. There are four:

| Layout | Style | How it thinks |
| --- | --- | --- |
| ಕೆಜಿಪಿ / ನುಡಿ (KGP) | keymap | Type by sound. `k` → `ಕ`, `A` → `ಾ`, `f` → `್`. |
| InScript | positional | Each physical key maps to a fixed letter (government standard). |
| InScript 2 | positional + extras | InScript plus direct ZWJ/ZWNJ keys and historic letters on the Alt layer. |
| Transliteration | phonetic | Spell Kannada in Roman letters: `k a n n a D a` → `ಕನ್ನಡ`. |

Pick **ಕೆಜಿಪಿ / ನುಡಿ (KGP)** if you type by sound and want the closest thing to the real Nudi keyboard. Pick **Transliteration** if you already know Roman spelling and want zero layout to memorise. Your choice is remembered in `localStorage`, so it survives reloads.

## Step 2: Type your first letter

Click the test surface on the **ಕೀಲಿಮಣೆ (Layout)** tab, then just type. The board below mirrors your physical keys live, and Shift flips the top-row legends.

Try these on KGP (key names are the physical keycaps, so `K` is the key labelled K; `⇧A` means Shift + A):

```
K, then ⇧A  ->  ಕಾ      pending ಕ composes with the matra  ಾ  on Shift+A
K, then ␣   ->  ಕ       the next key commits a lone consonant (here, space)
⇧K, then ⇧A ->  ಖಾ      Shift+K is the aspirate ಖ; Shift+A then finishes ಖಾ
```

KGP builds letters by key *combinations* and by sound. A consonant key like `K` does not emit immediately: it holds as a *pending* letter (shown as a preview) and the next key commits or extends it. `K` then `⇧A` gives `ಕಾ`, and `⇧K` gives the aspirate `ಖ`. This is the same behaviour as the real Nudi keyboard.

Every letter works the same way on the practice side: the tutor tells you the exact keys first.

## Step 3: Do one practice level

Click the **ಅಭ್ಯಾಸ (Practice)** tab. Level 1, **Vowels (ಸ್ವರಗಳು)**, is loaded. You'll see the target letter, the keys to press as `kbd` hints, and a progress bar.

1. Click the input box under the target.
2. Type the hinted keys exactly. The `kbd` hints below the target are generated by replaying your layout's own engine, so the suggested keys always produce the target akshara.
3. Correct letters turn green, wrong ones red. Complete all 15 vowels to finish the level.

When you finish a level, the app shows a checkmark and hands you off to the next one. WPM, accuracy, and streak are tracked per level from your first keystroke:

- **WPM** = completed characters ÷ 5, divided by minutes elapsed.
- **Accuracy** = correct keystrokes ÷ attempted keystrokes.
- **Streak** = consecutive completed items before a Skip.

## Step 4: Write freely

Switch to the **ಮುಕ್ತ ಬರಹ (Free Type)** tab. This is an open canvas: type anything, and Backspace deletes one full akshara (a visual syllable like `ಕಾ`) at a time, not one letter at a time, matching how a real Kannada IME behaves. Use **Copy text** to grab your composition.

## Step 5: Understand what you can type (optional but useful)

The **ಸಂಕೀರ್ಣ (Complex Chars)** tab has two halves:

- **Complex Character Cards** - examples like `ಕ್ಷಣ` with the exact keys that produce them and their raw Unicode codepoints. This is where you learn the non-obvious stuff: conjuncts, nukta forms, invisible joiners.
- **Full Unicode Coverage** - all 91 assigned Kannada codepoints (U+0C80–U+0CFF), colour-coded by whether the selected layout types them on a key, via a modifier, or not at all. A placeholder box there means your system font lacks that glyph.

This tab is equally useful for checking font rendering as for learning keys.

## What you built

You can now type Kannada on your everyday keyboard without installing anything: you picked and memorised a layout (KGP by syntax, InScript positionally, Transliteration by Roman spelling), practised through levels that scale from single vowels to full sentences, and used the Unicode reference to understand exactly what your chosen layout can and cannot produce.

Next steps:

- Work through the later levels: **Vowel signs**, **Words**, **Clusters & ligatures**, then **Sentences**.
- Switch layouts mid-lesson to see how the same akshara is typed differently.
- Use the digit toggle on the Layout tab to choose Kannada digits (`೦-೯`) vs Western (`0-9`).
